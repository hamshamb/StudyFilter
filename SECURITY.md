# Security policy

## Reporting a vulnerability

Please do not disclose security issues in a public GitHub issue.

Report vulnerabilities privately through GitHub's **Security → Report a vulnerability** flow for this repository. Include the affected route or component, reproduction steps, expected impact, and any suggested mitigation.

Do not include real student data, session tokens, API keys, or other secrets in the report. If a credential may have been exposed, revoke it immediately before continuing the investigation.

## Supported version

Security fixes target the current `main` branch and the currently deployed version at [studyfilter.online](https://studyfilter.online).

## Safe testing

Test only against accounts and data you own. Do not perform denial-of-service testing, automated credential attacks, social engineering, or actions that could affect other users.
